64 kbps 是什么意思

一课目标：把「码率 / bitrate」说成可算的量——每秒多少 bit，并会和仓库契约 PCM 字节账对照。

/teach 课 · 绑定 Learning「编码」· MISSION.md · 课记 · 速查 · 上节 0002

知识：bitrate 是「水龙头开多大」

编码时的 bitrate（码率）≈ 编码器平均每秒允许往外吐多少 bit 的压缩结果。本仓库钉死 kBitRateBps = 64000，口头常说 64 kbps（kilobits per second）。

RFC 6716 §2.1.1：Opus 支持约 6–510 kbit/s；同样条件下，码率越高通常质量越好。它给的是压缩码流的预算，不是采样率。

PCM 样本（很多字节）→ 编码器按 bitrate 预算挤小 → 码流（少很多 bit/s）

知识：先分清 bit 与 byte

64 kbps = 64_000 bit/s
÷ 8     =  8_000 byte/s   ← 载荷量级

同 1 秒内容：契约裸 PCM ≈ 96 000 B（课记）；64 kbps Opus 载荷量级 ≈ 8 000 B。CAF 文件还会多一点头。压缩比量级大约 96 000∶8 000 ≈ 12∶1（只比量级，别当精确听感公式）。

弱网自适应会改这个水龙头（升/降 bitrate）。本票实验固定 64 kbps，只叙述不实现。

知识：同是「64 kbps」，别和 G.711 撞车

电话 G.711：8 kHz × 8 bit/样本 = 64 kbit/s——那是未压缩（或仅压扩）电话 PCM 的自然数据率。你仓库的 64 kbps 是 Opus 压缩目标码率，吃的是 48 kHz 线性 s16le。数字碰巧一样，概念不是一路货。

测验

2. 64 kbps 换算成每秒大约多少字节？

动手（可选）

编码 1 秒输入后看日志 bitrate_bps=64000 与 output_bytes；再用 afinfo 看「audio bytes」是否落在约数千～一万量级（外加 CAF 头）。数字以课记为准。

指定精读

RFC 6716 §2.1.1 Bitrate — 读 sweet spots 那几行：语音常用带往往低于 64 kbit/s；64 更靠近「全带单声道音乐」量级。本票选 64 是学习钉死值，不是唯一正确语音点。
