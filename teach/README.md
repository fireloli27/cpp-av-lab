# `/teach` 教室（个人进修）

与 Learning Project 工程文档分开。工程资产在 `docs/learning/`；这里只放概念课、速查与书单。

| 文件 / 目录 | 用途 |
| --- | --- |
| `MISSION.md` | 为什么学 |
| `RESOURCES.md` | 外链书单 |
| `NOTES.md` | agent 教学备忘（人可略读） |
| `lessons/` | HTML 课（测验） |
| `reference/` | 速查表 |
| `assets/` | 课共用样式 / quiz |
| `learning-records/` | 学过什么的记录 |

**桥到工程：** 阶段契约与代码地图仍以 `docs/learning/.../*.notes.md` 为准；课只链接过去。

**语言：** 讲解正文用中文；术语 / API / 路径 / 命令 / 格式词保留英文（PCM、WAV、AudioQueue、ASBD、s16le 等），不硬翻成主标题。与仓库根 `AGENTS.md`「Doc language」一致。

从仓库根跑 `/teach` 时，把本目录当作教学工作区（或在对话里说明 workspace = `teach/`）。
