Transport Unit 速查

压缩表。仓库传输契约以 课记 为准；出处见 RESOURCES.md。

一句话

  • access unit：压缩码流里的一包（本路径 = Opus packet）。
  • Transport Unit：access unit + 本票分帧 → 可在环回发送/接收。见 GLOSSARY。
  • 本票分帧：uint32 BE length + 载荷（非 RTP）。见 ADR-0003。

对仗前几课

PCM  ≠ WAV
Opus ≠ CAF
frames_per_packet ≠ Transport Unit

单元形状（镜像课记；改数字先改课记）

Transport Unit = [len:4 BE][opus payload…]
len = payload bytes only（不含这 4 字节）
无 seq / timestamp / SSRC

环回 = 单进程 POSIX UDP · 127.0.0.1 · bind :0
产物 = out/audio/local-transport/loopback-ok.txt
读包 = AudioFileReadPacketData（CAF → Opus 包）

管线位置

编码 Opus → 本地传输/打包（Transport Unit）→ [jitter·不做] → 解码 → …

学习选型 ≠ 产品必须 RTP。jitter：接收后、解码前（叙述必会）。
