PCM 是样本，WAV 是盒子

一课目标：分清「样本布局」与「文件容器」，并会用采集契约算 1 秒裸 PCM 字节数。

/teach 课 · 绑定 Learning「采集」· MISSION.md · 课记（契约权威） · 速查 · 短文（怎么跑）

知识：两个不同的词

PCM：样本怎么数字化、怎么排（采样率、声道、位深、端序）。不是文件格式；内存里可以是 vector<int16_t>。

WAV（本语境）：RIFF/WAVE 容器—— fmt 写明格式， data 装着 PCM 字节。见 Microsoft RIFF / WAVEFORMATEX。

麦克风 → 线性 PCM 样本串 → 装进 WAV（fmt + data）→ *.wav

Core Audio：sample / frame / packet 定义见 ASBD。本仓库采集为 mono 线性 PCM 时，一帧 = 一个 int16。实现细节只维护在课记，不在本课复制代码表。

知识：用契约算字节账

数字以课记「契约」表为准（当前：48 kHz · mono · s16le）。公式： 

nBlockAlign     = channels × (bits/8)
nAvgBytesPerSec = sampleRate × nBlockAlign

代入当前契约 → 2 字节/帧、 96 000 B/s 裸 PCM。公式字段对应 WAVEFORMATEX；若课记改了采样率，重算这里，不要两处各写死一套。

知识：别把「PCM」当成 G.711

ITU-T G.711 也叫 PCM，但是 8 kHz + 8-bit A-law/µ-law。仓库采集是线性 s16le。口头说 PCM 时先问清哪一种。
