# 〈阶段短文标题〉

正文中文；路径 / 命令 / 目标名 / GLOSSARY 术语与格式词保留英文（见 `AGENTS.md` Doc language）。

## 目标

对应哪一段 Learning Pipeline Stage（采集 / 编码 / 本地传输/打包 / 解码 / 渲染），音或视，要验证什么概念。

## 前置

工具、权限、输入文件、cwd 约定等。

## 选用库

本阶段选用的库或系统 API；尚未选用写「无」或「待本票选定」。

## 运行步骤

配置、编译、从仓库根运行的具体命令。

## 可观察成功判据

成功时应出现的文件、窗口、声音或日志摘要；须可人为确认。

## 失败时仍记录什么

卡住时短文仍应记下的错误现象、边界与下一步假设。

## 与主缝关系

本阶段提供独立可执行入口；人工按本文步骤验收。不依赖统一 pipeline runner。
